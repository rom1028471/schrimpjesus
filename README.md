# Schrimpjesus — ридер рассказов с триггерами картинок и музыки

Минималистичный ридер для собственных рассказов. Поддерживает мобильные и десктопные экраны, скролл — на контейнере, а не на `window`. В определённых местах включаются изображения и бесшовные музыкальные лупы с плавным появлением/исчезновением.

## Быстрый старт

```bash
npm i
npm run dev
```

Откроется dev-сервер Vite (по умолчанию `http://localhost:3000`).

## Структура контента

- Работы (тексты, PDF, метаданные) — в `public/works/`
  - `public/works/metadata.json` — список работ (одна точка правды)
  - `public/works/*.md` — исходные тексты с маркерами
  - `public/works/*.pdf` — опциональные PDF
- Медиа — в `public/assets/`
  - `public/assets/images/*` — изображения, которые подхватывает ридер
  - `public/assets/audio/*` — треки для музыкальных маркеров

Пример маркеров в тексте `.md`:

```
Текст, текст...
[image: cover1.jpg]
Ещё текст...
[music: MT.mp3, radius=0.35]
```

- `[image: <file>]` — вставляет «окно» в тексте; соответствующая картинка фиксированно показывается под текстом, когда окно в зоне видимости
- `[music: <file>, radius=<0..1>]` — включает/выключает луп трека при приближении к центру вьюпорта. `radius` — доля высоты вьюпорта, определяющая зону активации (по умолчанию `0.3`).

## Аудио-логика (кратко)
- Автоплей: при входе в зону воспроизведение поднимается плавно (fade-in ~5s) с 0 до целевой громкости; при выходе — плавно затухает (fade-out ~5s).
- Луп: трек играет по кругу, пока пользователь в зоне.
- Память позиции: при выходе из зоны текущая позиция трека сохраняется; если пользователь вернётся в течение 30 секунд — трек продолжится с места паузы, иначе начнётся с начала. Память ведётся отдельно для каждого файла.
- Громкость и mute доступны в хедере.

## Команды

- Dev:
  ```bash
  npm run dev
  ```
- Линт (опционально):
  ```bash
  npm run lint
  ```
- Превью локальной прод-сборки:
  ```bash
  npm run preview
  ```
- Сборка для GitHub Pages (в папку `docs/`):
  ```bash
  npm run build:docs
  ```
- Публикация на GitHub Pages (ветка `gh-pages`):
  ```bash
  npm run predeploy && npm run deploy
  ```

## Деплой на GitHub Pages
- `package.json` настроен с `homepage` и `base: '/schrimpjesus/'`.
- Сборка для Pages — в каталог `docs/` (`vite.docs.config.js`).
- Скрипты:
  - `predeploy`: собирает `docs/`
  - `deploy`: публикует содержимое `docs/` через `gh-pages`

Важно: если вы меняете имя репозитория или org/user — обновите `homepage` в `package.json` и `base` в `vite.docs.config.js`.

## Примечания по разработке
- Скролл слушается только у внутреннего контейнера — это важно для воспроизведения и синхронизации эффектов.
- В прод-сборке отключены отладочные логи.
- При добавлении больших текстов рекомендовано проверять производительность на мобильных: предрасчёт индексов блоков уже оптимизирует скролл, но изображения большой ширины могут влиять на затраты разметки.

## Лицензия
Только для личного использования автора. Все права на тексты и медиа принадлежат автору.
